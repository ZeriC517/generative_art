# generative_art# 🌌 Elite Generative Art & Wallpaper Engine

A high-performance, browser-based generative art and physics engine built entirely with HTML5 Canvas and Vanilla JavaScript. This application combines complex mathematical algorithms, physics simulations, and visual design to create stunning, one-of-a-kind digital art and dynamic 4K wallpapers.

---

## ✨ Features

* **5 Unique Algorithmic Render Modes:**
    * **Fluid Flow Streamers:** Organic, curving currents driven by trigonometric formulas.
    * **Topographic Contours:** Simulates 2D geographic elevation mapping using complex pseudo-Perlin intersecting sine waves.
    * **Constellation Plexus:** Neural network/starry effects created by measuring proximity and linking nearby particles.
    * **N-Body Gravitational Orbitals:** Accurate inverse-square law physics simulating invisible gravity wells pulling particles into elliptical spirographs.
    * **Recursive Spirals:** Expanding central vortexes mapping time against rotational radius.
* **Mandala Symmetry Engine:** Real-time matrix rotations transforming chaotic patterns into perfect 4-way, 8-way, or 12-way sacred geometry.
* **Advanced Kinetic Physics:** * *Kinetic Spawning:* Click and drag across the void to spawn particle streams with inherited velocity.
    * *Slingshot Mechanics:* Grab an existing particle and pull it back like a rubber band to disrupt the physics field.
    * *Magnetic Cursors:* Attract (Black Hole) or Repel (Force Field) particles.
* **GPU Blending & Custom Palettes:** Features "Screen" and "Lighter" composite operations for vibrant neon stacking, plus custom hex code pickers to design your own colorways.
* **Cinematic 4K Export:** Instantly calculate and render an off-screen, ultra-high-definition (3840x2160) snapshot of your current settings.

## 🚀 How to Run

Because this project is built entirely with frontend web technologies, there are no dependencies, servers, or build tools required.

1. Create a new file named `generative_art.html`.
2. Copy and paste the provided application code into the file.
3. Save the file.
4. Double-click the file to open it in any modern web browser (Chrome, Edge, Firefox, Safari).

## ⚙️ Under the Hood (Tech Stack & Math)

* **HTML5 Canvas API:** Handles all real-time rendering and dynamic alpha-trail motion blurring.
* **Vanilla JavaScript:** Powers the animation loop (`requestAnimationFrame`) and UI state management.
* **Trigonometry:** Sine and cosine functions are heavily mapped across coordinate spaces to create flow fields and topographic noise.
* **Orbital Mechanics:** Uses the Inverse-Square Law to calculate exact gravitational pull based on particle mass and distance.
* **Pythagorean Theorem:** Calculates real-time distance (`Math.hypot`) between thousands of nodes per frame to generate the Plexus webs.
